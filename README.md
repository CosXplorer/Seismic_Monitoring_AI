# AI-Powered Seismic Monitoring System

A deep learning based seismic event classification platform built using PyTorch, ObsPy and Streamlit.

## Features

* Earthquake Detection
* Avalanche Detection
* Noise Classification
* MiniSEED Support
* Spectrogram Visualization
* Batch Classification
* CSV Export
* Example Event Explorer

## Model Performance

* Test Accuracy: 80.02%
* Classes: Noise, Avalanche, Earthquake

## Tech Stack

* Python
* PyTorch
* Streamlit
* ObsPy
* NumPy
* Pandas
* Matplotlib
* SciPy
